# Corrections import portefeuille

- Le champ `Table ou vue à importer` est maintenant une vraie liste déroulante `<select>` avec le même style que les autres champs du formulaire.
- Le message technique `Import portefeuille : choisissez seulement la table/vue...` a été retiré.
- Le bloc explicatif PostGIS automatique a été retiré du formulaire pour simplifier l’écran.
- Le champ `Description optionnelle` a été retiré du formulaire d’ajout.
- Les paramètres techniques restent disponibles uniquement dans `Paramètres techniques avancés`.
